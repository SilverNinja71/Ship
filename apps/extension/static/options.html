The Lookout

Settings for Ship's focus guard

Gemini, the video judge

During a focus block, the Lookout asks Gemini whether a YouTube video fits the assignment you're working on. Without a key, a simpler keyword check decides, and says so.

Get a free key from Google AI Studio. It is kept only in this browser and sent only to Google's Gemini API.

gemini-flash-latest always points at Google's newest Flash model. Model names change, so you can pin a specific one here instead.

Your Ship

Where "Steer back to the ship" sails to. The Lookout also listens for your voyages on this page.

Usually http://localhost:5173 while you run npm run dev.

Blocked sites

These are blocked only while a focus block is running. Subdomains count too, so reddit.com covers old.reddit.com.

Chrome will ask to let the Lookout see that site, so it can put up the gate there.

    Always on during focus blocks, no setup needed:
    • YouTube home, Shorts and feeds (subscriptions, trending, explore) are blocked.
    • YouTube videos are judged against your assignment. Search, channels and playlists stay open so you can find lectures.
